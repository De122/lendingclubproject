WORKING ON AN EXISTING PROJECT 

1. Go the desired project repo and click on fork and then on copy the main branch to bring it to your account. 
2. Then you can clone it to your local. 

Whatever changes we do to this forked project, is only reflected in out repo and not on the other account's repo.

But, we can create a pull request so that the changes from our github account in feature1 branch can be merged to upstream main branch. Then some approvers approve it.
